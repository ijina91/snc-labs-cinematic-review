# 첫 스크롤 고정 및 제작 잔여물 정리

2026-11-05

## 수정

첫 화면의 고정 컨트롤러가 지연 로딩되는 동안 스크롤하면, 로딩 완료 시 화면이 아래로 다시 움직였습니다. 의도적으로 해당 모듈을 늦춘 기존 코드에서 40px 이동을 재현했습니다. 별도의 늦은 GSAP 진입 효과도 이미 보이는 제목을 8–12px 아래로 움직였습니다.

첫 화면 컨트롤러를 초기 모듈에 포함하고 첫 실행 작업에서 초기화합니다. 중복된 제목 진입 효과는 제거했습니다. 기존 영상의 1.05초 진입, 35초 스크롤 시간축, 역방향 탐색, 모션 감소와 낮은 가로 화면의 일반 읽기 흐름은 유지합니다. 이후 섹션의 GSAP는 계속 지연 로딩합니다.

## 정리 범위

- 완료된 정리 패스에서 제작 중간 파일 652개, 739,155,663바이트를 삭제했습니다. 앞선 패스에서 삭제한 원본과 해시가 같은 외부 중복 파일은 이 수치에 포함하지 않습니다.
- 사용하지 않는 v1/v2 프레임, 이전 영상 4개와 일회성 제작 스크립트 2개를 저장소에서 제거했습니다. 문의 섹션의 마지막 정지 화면은 동일한 v3 자산으로 연결했습니다.
- 원본 첨부 자료, 현재 v3 영상·프레임, 폰트 소스와 라이선스, 브라우저·원격 접속 설정은 보존했습니다. 실행 중인 미리보기의 로그 4개는 해당 프로세스가 사용하므로 남겼습니다.
- [정리 기록](verification/opening-scroll-cleanup.json). Git 추적 파일의 이전 버전은 Git 이력으로 복구할 수 있습니다.

## 검증

- 기존 코드에서 지연 로딩 첫 스크롤 회귀 검사가 40px 이동으로 실패하는 것을 확인했습니다.
- 수정 후 진입 검사: 6개 통과, 화면 조건에 따른 6개 제외. 새 첫 스크롤 검사는 390/768/1440/1920px에서 영상·제목·대형 문구의 이동 범위가 각각 1.5px 이내임을 확인합니다.
- 영상 진입·역탐색·늦은 영상 로딩, 폴드 펼침·회전, 빠른 터치, 입구·출구 고정, 선택 모션 번들 실패 검사: 23개 통과, 화면 조건에 따른 9개 제외.
- 별도 첫 스크롤 실측: 390px와 폴드 690px에서는 이동 0px, 1440/1920px에서는 최대 1px. 모든 폭에서 가로 넘침·페이지 오류·실패한 자산 요청 0건. [실측 기록](verification/opening-scroll-proof.json), [모바일 캡처](previews/opening-scroll-390.png), [데스크톱 캡처](previews/opening-scroll-1440.png).
- 프로덕션 빌드와 소스·SEO·배포 가드 검증 통과. 성능 점수를 이번에 새로 측정하지 않았습니다.
- 최종 전체 회귀 검사: 98개 통과, 30개는 해당 화면 조건에 적용하지 않아 제외, 실패·불안정 재시도 0건. 390/768/1440/1920px의 콘텐츠·자산·링크·키보드·axe 접근성·GitHub API 상태·모션 감소·JavaScript 비활성화·영상 대체 상태를 포함합니다. [전체 검증 기록](verification/opening-scroll-qa.json). 검증 요약과 최종 캡처를 보존하고 이번 검사 원본 임시 파일은 휴지통으로 정리했습니다.
- 현재 v3 영상 SHA-256은 변경 전과 동일합니다. 데스크톱 `ccc0607f3eb4f73b1b88c631d0e6fc5319fadb99bf62998499a1786eb7c5ef1a`, 모바일 `69c6d70cf41d080ed0076bb1caa704800ac840c883c9da87dbce750f1f950da9`.

사용자가 이번 수정의 즉시 운영 반영을 요청했습니다. 운영 배포 성공 여부는 실제 main 병합과 Pages 완료 후 확인해야 합니다.
