# SNC 무료 영상 제작 상태

확인일: 2026-11-04 (한국 시간). **영상 생성 및 사이트 적용 완료 상태가 아니다.**

## 새 방향과 현재 적용 범위

회전하는 체크마크와 체크 외곽 고리, 장면별 독립 3D 모델을 제거했다. 첫 화면과 여섯 장면에는 이번 프로젝트에서 만든 비대칭 블루 건축 공간의 원본 첫 프레임을 적용했다. 오른쪽 점 내비게이션과 장면 번호도 제거했다. 흰색으로 시작하는 유한 진입 애니메이션, 기본 스크롤, 회사 소개·서비스·문의·GitHub 기능은 유지한다.

현재 배경은 정지 이미지다. 이를 생성된 영상이나 완성된 연속 촬영으로 설명하지 않는다. 실제 원본을 확보하고 검수하기 전까지 src/data/film.js의 source는 빈 값이며, 존재하지 않는 MP4를 요청하지 않는다. 스크롤이 video.currentTime을 소유하는 재생 모듈은 준비했지만 실제 외부 생성 영상으로 검증하지 않았다.

## 제출한 영상 프롬프트

SNC 기업 웹사이트를 위한 한 번의 연속 카메라 이동. 카메라가 이 거대한 순백의 공간 속으로 부드럽게 전진하며 오른쪽의 코발트 블루 곡면 금속 구조물을 지나간다. 전경의 푸른 구조와 투명한 유리판이 자연스럽게 카메라 옆으로 지나가며 배경의 새로운 블루 공간이 드러난다. 스카이 블루 빛이 바닥의 곡선을 따라 깊은 곳으로 흐르고 정교한 반사광이 금속 표면을 스친다. 공간의 원근 변화와 입체적인 시차가 확실해야 한다. 처음부터 끝까지 같은 공간과 같은 재질을 유지하고 중간 컷이나 갑작스러운 변형 없이 하나의 우아한 촬영으로 이어진다. 흰색, #216BE4 블루, #36A4ED 하늘색, #21386D 네이비만 사용. 왼쪽은 문구를 읽기 위한 밝고 정돈된 여백. 대형 기업 브랜드 필름 수준의 매끄럽고 놀라운 공간감. 체크마크, 로고, 글자, 숫자, 원, 고리, 구체, 사람, 초록색, 보라색, 빨강색, 반짝이 파티클, 워터마크를 추가하지 않는다. 흔들림과 깜빡임과 뭉개짐 없이 선명하고 자연스럽게 움직인다.

- 9222의 /json/version·/json/list·/json 및 루트가 HTTP 404를 반환했고, 사용자도 해당 디버그 주소에 연결할 수 없다고 확인했다. 이번 실행의 도구 목록에는 이전 브라우저 세션 연결 도구가 없다. 별도 준비한 브라우저도 사용자에게 동작하지 않는다고 보고받아 기존 연결 복구 단계가 남았다.

## 시각 검토

긍정 검토: 새 원본 공간이 SNC 블루·화이트와 일치하고 체크마크 없이 전체 배경을 채운다. 73KB WebP로 정지 대체 자산을 제공한다.

부정 검토: 첫 캡처에서 이미지가 콘텐츠 컨테이너 안에 갇혀 테두리처럼 보이고, 문구 보호막의 가로 경계가 드러났다. 이미지를 전체 stage로 옮기고 전체 높이 그라데이션으로 수정했다. 모바일의 position: relative 잔존도 absolute로 바로잡았다. 하단 기술 링크에는 밝은 배경과 44px 조작 영역을 적용했다. 실제 영상의 화질·연속성·길이는 여전히 검수할 수 없어 품질 완료 점수를 부여하지 않는다.

최종 전체 배경 배치 후 16건 추가 검사 중 15건 통과. 모바일의 중첩된 기본 키보드 스크롤 입력 대기를 바로잡은 뒤 해당 흐름을 네 화면 크기에서 재실행하여 4/4 통과했다. [실제 검증 기록](../verification/qa-film-preparation.json)에 최초 실패와 재검사를 함께 보존했다.
