## 실제 제작과 출처

이번 프로젝트에서 imagegen으로 새로 만든 SNC 공간 원본을 시작 이미지로 사용했다. LoreMotion 로그인은 사용자가 직접 완료했다. 기본 인앱 브라우저로 정상 파일 선택기·생성 UI·다운로드를 사용했으며 전체 CDP 접근은 추가 활성화하지 않았다. 유료 모델·결제·유료 크레딧은 사용하지 않았다.

각 요청의 Free·720p·5초·16:9와 업로드 완료를 UI에서 확인했다. 중복 제출하지 않고 기존 대기열·렌더·Done을 확인했다. 공급자는 720p라고 표시하지만 실제 출력 세로는 704px이다. 원본은 ignored artifacts/video-source에 보존했다. 작업 ID는 완료 결과의 자체 video src에서 확인했으며 커뮤니티/데모 영상은 사용하지 않았다.

영상은 매끈한 비대칭 블루 금속·유리·밝은 공간을 유지한다. 세 구간의 샘플 프레임을 각각 검토하고 연결 후 전체 파일을 디코딩했다. 첫 구간의 전경이 지나가며 안쪽 공간을 드러내고, 두 번째·세 번째 구간에서 같은 공간을 따라 계속 이동한다. 별도 회전 체크마크·외곽 고리·글자·고객 로고는 넣지 않았다. [최종 프레임 시트](../previews/film-contact-sheet.png).

## 최종 웹 파일

- 경로: `public/assets/media/snc-spatial-film.mp4`
- 길이: **15.50초**, **372프레임**, **1280×704**, **24fps CFR**.
- H.264 High Level 3.1, yuv420p, 무음, faststart, 키프레임 간격 12프레임.
- 크기: **4,695,423 bytes**. 프롬프트 등 원본 메타데이터는 제거했다.
- 원본 해시·최종 해시·사양: [기계 판독 기록](../verification/film.json).
- FFmpeg 전체 프레임 디코딩 성공. 웹 압축·프레임 시트 생성 후 실제 픽셀 검토 완료.

이는 **세 번 생성한 연속 구간을 편집한 결과**다. 하나의 15.5초 생성 작업, 네이티브 1080p/4K, 5초 반복 또는 정지 이미지 확대 영상으로 설명하지 않는다. 24fps로 프레임 간격을 정리했으며 임의로 느리게 늘리지 않았다. 원본 음성/음악은 장식 배경에 필요하지 않아 제거했다.

## 사이트 적용

src/data/film.js가 실제 MP4를 가리킨다. 첫 화면은 고해상도 원본 WebP로 화이트→블루 진입을 유지하고, 이후 여섯 소개 장면에서는 하나의 MP4를 스크롤 위치에 맞춰 탐색한다. 위로 스크롤하면 영상도 돌아간다. 회전 체크·고리 중심 WebGL·Three.js 의존성·오른쪽 점과 번호는 제거했다.

자동재생·반복재생·스크롤 잠금을 사용하지 않는다. 화면 근처까지 영상 다운로드를 지연하고, 저사양/데이터 절약·영상 오류는 원본 정지 배경으로 대체한다. Reduced Motion·JavaScript 비활성화는 일반 읽기 흐름을 유지한다. 실제 재생·실패·모션 설정 변경 검증은 [QA 기록](../verification/qa-film.json)에 있다.

## 미채택·이전 시도

- 초기 LoreMotion LTX text-to-video `8638a091-6016-401a-a24a-f4d32c99e4ec`: 실제 생성·다운로드했다. 주름진 금속 표면과 원형 통로가 요구에 맞지 않아 미채택했고 사이트에 포함하지 않았다.
- 두 번째 익명 제출은 Sign up free 안내로 거절됐다. 제한을 우회하지 않고 사용자의 로그인 후 위 MiniMax 작업으로 진행했다.
- 과거 Vheer는 업로드 후 작업 ID/완료 파일이 노출되지 않아 미해결로 보존했다. Donatello는 해당 세션의 로그인/연결이 없어 제출하지 않았다. 이전 헤드리스 LoreMotion은 사람 인증 단계에서 중단됐다. 이 과거 상태를 현재 브라우저의 접수 성공과 혼동하지 않는다.
- 무료 연장 UI의 혼잡 시 720p 총 5초 / 480p 총 10초 한계를 확인했다. 이후 위 세 구간은 정상 image-to-video 기능으로 순차 제작했다. 유료 길이 옵션이나 숨겨진 API로 우회하지 않았다.

## 권리와 공개 범위

[Vheer 약관 11.2](https://vheer.com/terms), [영상 안내](https://vheer.com/ai-image-to-video), [Donatello 제품 정보](https://donatello.studio/product-facts)는 이전 경로 검토 자료이며 최종 소스의 출처가 아니다.
