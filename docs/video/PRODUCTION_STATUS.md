## 웹용 마스터

일곱 구간을 각 5초·120프레임으로 정규화해 페이드 없이 실제 인접 프레임으로 연결했다. 최종 파일은 정확히 **35초·840프레임·24fps**, H.264/yuv420p, 무음, faststart, 짧은 키프레임 간격이다. 메타데이터의 생성 프롬프트와 오디오는 웹용 파일에서 제거했다. 초기 인코딩은 구간마다 1프레임씩 부족해 미채택했고, 마지막 샘플 배출과 실제 프레임 수 검사를 보완한 뒤 다시 만들었다.

데스크톱·모바일 파일 모두 전체 디코딩, 여섯 접합의 앞뒤 프레임 비교, 끝까지의 브라우저 재생을 확인했다. 접합 RGB RMSE는 보조 지표이며 시각 검수의 대체 점수가 아니다. 실제 파일 해시와 사양은 [미디어 원장](../verification/film-v2.json)에 기록한다. 전체 웹의 모바일·폴드·접근성·성능 검사는 [QA 보고서](../../QA_REPORT.md)에서 별도로 확인한다.

## 권리와 공개 범위

사용자가 SNC 사이트용으로 제공한 디자인을 사용했다. 공급자 UI의 무료·워터마크 없음·상업 이용 안내를 확인했으며 모델 조건을 전제로 한다. Pinterest·GitHub·Instagram 원작의 영상·이미지·음악·코드를 복사하지 않았다. 실제 고객 시스템·내부 주소·토큰·개인 연락처를 포함하지 않는다.

## 지정 시간 수정 v3

사용자는 전체 장면 재제작이 아닌 10–13초·21–27초만의 수정을 요청했다. 실제 24초 기준점을 사용해 연결을 고정했다. 디졸브가 생긴 긴 시도와 어울리지 않는 결정 조형은 미채택했다. [최신 수정·선택·제외 기록](TIMED_REPAIRS.md), [v3 소스·사양·해시](../verification/film-v3.json)를 확인한다. 두 웹 파일은 35초·840프레임·24fps이며 오디오가 없다. 사용자가 QA 통과 후 즉시 운영 반영을 명시적으로 승인했다.
