# 지정 시간 구간 영상 수정

2026-11-05 (Asia/Seoul). 수정 범위는 기존 35초 마스터의 **10–13초와 21–27초**다. 장면 05·06 전체를 다시 만들지 않는다. 시작 SNC 로고, 검정·SNC 블루, 01–07 순서, 구간 밖의 화면과 길이를 보존한다. 웹 출력 재압축에 따른 픽셀 차이와 내용 변경은 구분한다.

## 적용 방식

10초와 13초의 실제 원본 프레임을 양끝으로 지정해 유리 모듈을 지나가는 이동을 다시 연결했다. 21–27초는 실제 24초 프레임을 중간 기준점으로 사용했다. 먼 배경의 글자처럼 보이는 큐브 군집·계단 연결·바닥 반사를 없애고 주변과 같은 작은 청색 기둥과 유리 블록으로 채웠다. 24–27초의 시작은 직전 채택 결과의 실제 마지막 디코딩 프레임이다. 가까운 기둥이 배경을 자연스럽게 가리는 원본 27초 구도로 복귀한다.

무료 LoreMotion MiniMax H3의 공개 UI에서 3초·720p·첫/끝 프레임으로 각각 제출했다. 세 원본 모두 실제 1280×704·24fps·107프레임(4.458초)이므로 공급자 설정 표기와 실제 출력 길이를 구분하고, 각각 정확한 3초·72프레임으로 맞췄다. 전체 길이와 기존 스크롤 시간축은 바꾸지 않는다. FFmpeg는 로컬 CPU 편집에 사용하며 유료 생성 API·새 런타임 의존성은 추가하지 않았다.

## 이미지 편집 기록

내장 **imagegen**으로 실제 24초 프레임의 먼 배경만 편집했다. CLI/API 키 경로는 사용하지 않았다. 선택한 중간 입력은 로컬 `artifacts/time-edit-v3/frame-24.00-matched.png`에 보관하며 최종 영상의 생성 기준으로 사용했다. 프롬프트는 다음과 같다.

> 첫 번째 이미지 원본 동영상의24초 프레임을 정밀하게 부분 편집한다. 카메라 구도와 모든 전경을 그대로 보존한다. 제거 대상은 오른쪽 먼 배경에 있는 S/C 알파벳처럼 보이는 두 개의 작은 빛나는 큐브 군집과 그 사이 계단 연결뿐(화면 가로74~89%, 세로60~70%)이다. 이 글자 모양과 그 아래 바닥 반사를 없앤다. 그 자리는 같은 화면의 주변 건축물과 똑같은 재질과 형태로 자연스럽게 채운다: 기존 뒷배경과 같은 짙은 파란 직육면체 기둥 두 개를 서로 다른 낮은 높이로 세우고, 그 옆에 기존 중앙 기둥에 붙어 있는 것과 같은 작은 투명 유리 정육면체 두세 개를 단정하게 배치한다. 새로운 스타일을 만들지 말고 바로 옆 기둥과 유리 블록을 작게 반복해 원래 이 장소에 있던 구조물처럼 보이게 한다. 글자나 로고로 읽히면 안 된다. 삼각형 결정, 뾰족한 크리스털, 보석, 사선 조각, 빛나는 원, 고리, 구체 금지. 낮고 자연스러운 배경 건축 요소여야 한다. 기존 기둥, 왼쪽 큰 투명 블록, 바닥, 대각선 파란빛 두 줄과 다른 모든 요소는 변경하지 않는다. 바닥 반사를 새 작은 기둥과 큐브에 맞춰 조용히 수정한다. 원본과 같은 검정/파랑/청백색 광원, 같은 원근감과 선명도, 텍스트 없음.
