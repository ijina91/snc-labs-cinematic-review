# 검은 배경·01~07 검증 안내

현재 디자인은 사용자 제공 일곱 프레임, 검은 배경과 SNC 블루 유리 공간을 기준으로 한다. v1 카메라 위주 시도와 예전 화이트 운영 버전의 결과를 최신 통과 기록으로 재사용하지 않는다.

최신 v3는 원본의 10–13초·21–27초만 수정했다. [실제 시간 구간 수정과 채택/제외](video/TIMED_REPAIRS.md), [v3 검증 데이터](verification/qa-film-v3.json), [새 파일·해시](verification/film-v3.json)를 우선 확인한다. 아래 내용은 유지한 기반 기능과 이전 검사 이력이다.

## 영상

일곱 채택 원본을 무료 도구에서 실제 생성·다운로드·전체 디코딩·시각 검수했다. 실제 직전 끝 프레임에서 다음 생성이 시작되며, 웹용 두 파일은 정확히 35초·840프레임·24fps다. 여섯 압축 연결부와 데스크톱·모바일 끝까지 재생을 확인했다. 원형 궤도가 남은 04→05 첫 결과는 미채택하고 입력 이미지부터 수정했다.

[제작 기록](video/PRODUCTION_STATUS.md), [소스·해시·실제 사양](verification/film-v2.json), [접합 프레임](previews/film-v2-contact-sheet.jpg).

## 확인한 주요 수정

- 첫 화면도 같은 일곱 패널과 단일 플레이어에 포함했다. 초기 약 1.05초 무음 진입 뒤 스크롤이 이어받고 반복하지 않는다.
- 모바일 초기 여백 차이의 16~24px 이동을 수정하고 280·320·390px에서 준비 전후 위치와 CLS를 검사했다.
- 비활성 패널이 겹치는 배치로 바뀔 때 잠깐 표시되던 초기 CLS를 수정했다. 실제 레이아웃 이동 관찰자를 검사에 포함했다.
- 모바일 부모 클리핑, SVH 본문/LVH 그래픽, 하단 잔여 공간, 늦은 페인트와 폴드 폭 전환을 검사한다.
- 늦게 로드된 영상은 목표 프레임 디코딩 후 표시하며, 정리 시 소스·이벤트·관찰자·rAF를 해제한다.
- 280px 문의 제목과 전화번호 배치를 별도로 조정했다.
- 실제 GitHub 목록 제목에 남은 어두운 색상을 밝은 블루로 수정하고 목록 상태의 대비 검사를 유지했다.
- no-JS·모션 축소·이미지/영상 실패·API 실패·시간제한·재시도·키보드를 각각 검증한다.

최신 테스트 실행 결과·수정 후 재검사·실기기 범위의 한계는 [QA 보고서](../QA_REPORT.md), 실제 성능 수치는 [성능 보고서](../PERFORMANCE_REPORT.md)에 기록한다. [장점·결함 교차 검토와 100점 기준](BLUE_GLASS_REVIEW.md)을 별도로 제공한다. 목표 점수와 실측을 혼동하지 않는다.

운영 배포는 별도 단계다. 사용자가 지정 구간 수정 완료 후 즉시 반영을 승인했으며, 최종 QA와 PR 검증을 통과한 버전을 기존 main/Pages workflow로 배포한다.
