# 검은 배경·01~07 리디자인 검증

## 현재 단계

이 문서는 제작 중 기록이다. 7개 영상 생성·통합 또는 운영 배포 완료 보고서가 아니다.

### v2 작업으로 대체 (최신)

아래 v1 제작 기록은 과거 이력이다. 사용자는 카메라 이동에 치우친 01~04를 채택하지 않았으며, 최종 영상 검수 통과 기록으로 사용할 수 없다. v2는 조각의 독립적인 움직임·반짝임·인접 장면 연결을 다시 검수한다.

- 첫 화면부터 07까지 7개 패널과 하나의 장식용 플레이어로 통합. 별도 01 재생기는 사용하지 않는다.
- 01~07의 평면 메뉴·글씨를 제작 이미지에서 제거. 07의 구체·원형 노드 및 곡선 연결선도 사용자 지시에 따라 제거.
- 검수되지 않은 v2 영상은 아직 연결하지 않았고, 정적 키프레임을 정상 대체 화면으로 제공한다.
- 새 구조에서 390px의 작은 화면 문구 배치, 하단 잔여 공간, 지연된 고정 화면 누출 방지, 폴드 접기·펼치기 및 회전 검사 4건 통과.
- v2 01→02, 02→03, 03→04는 무료 MiniMax H3로 실제 생성·다운로드·전체 디코딩·프레임 시각 검수를 마쳤다. 각 실제 비디오 스트림은 1280×704 / 24fps / 124프레임, 약 5.1667초다. 컨테이너의 더 긴 오디오 길이와 구분한다.
- 04→05는 1회 접수해 대기 중이다. 05→06, 06→07, 07 마무리는 아직 생성하지 않았다. 전체 영상 통합·최종 회귀·최종 성능 측정·PR·운영 배포는 미완료다.
- 01→02 수정 검토본은 사용자 본인의 Slack에 공유했고 파일 메시지를 확인했다. 전달 확인은 사용자의 채택·운영 배포 승인과 구분한다.
- 새 7장면 구조에서 4개 대표 너비의 기능·키보드·WCAG axe·정적 읽기·역방향 스크롤 등 24건을 통과했다. 낮은 데스크톱 창의 레이아웃 보존 및 정적 읽기 전환 1건도 통과했다.
- 데스크톱에서 CSS smooth 앵커 이동과 GSAP 측정 복원이 겹쳐 홈 링크가 끝까지 올라가지 않는 결함을 발견했다. 기본 앵커 이동을 즉시 완료하도록 바꾸고 해당 검사와 4개 너비의 회귀에서 통과했다.
- 늦게 로드된 영상이 첫 프레임을 먼저 보여주는 경로도 수정했다. 목표 프레임 디코딩 이후 표시하며 전체 소스 통합 후 실제 영상으로 추가 검증한다.

### v1 이력 (미채택)

- 사용자 ZIP: 01.png~07.png 7개, 원본 해시를 로컬 제작 원장에 보존.
- 사이트 순서: 첫 화면 01 + 스크롤 소개 02~07. 빌드 시 정확한 순서를 검사.
- 01: LoreMotion / MiniMax H3 / 무료 / 원본 작업 60bd8509-314c-42a5-81d1-42c00e5652f8. 원본 1280×704, 24fps, 5.17초. 전체 디코딩 성공, 3D SNC와 블루·검정 재질 시각 검수.
- 원본 첫 부분의 평면 UI를 피하기 위해 웹용 01은 0.5초 이후를 사용한다. 약간의 속도 조정으로 5초를 구성하고 음성과 생성 메타데이터를 제거했다. 원본은 별도로 보존한다.
- 02: LoreMotion / LTX 2.5 / 무료. 작업 c950ddc2-4252-4a6d-a45c-393310b6ee27 완료·다운로드·전체 디코딩 성공. 1280×704, 24fps, 5.04초. 입체 SNC와 반사광을 검수했으며 참조 이미지의 상단 평면 글씨는 웹의 검은 상단 마스크로 가린다.
- 03: 무료 MiniMax H3의 시작·마지막 프레임 설정을 확인하고 03 → 04를 참조해 접수했다. 04~07은 준비 단계이며 생성 완료로 표시하지 않는다.

## 디자인·기능 검증

- 1440×1000, 390×844, 690×829에서 가로 넘침 없음. 헤더 포함 첫 화면 높이는 각각 해당 뷰포트 높이에 맞음.
- 첫 axe 검사에서 GitHub 패널 제목 대비 1건 발견. 직접 자식의 이전 색상 규칙이 원인이어서 해당 텍스트 색상을 수정.
- 수정 뒤 390 / 1440의 WCAG 자동 검사 2건 통과.
- 모바일·폴드 회귀 실행: 6건 통과, 2건 실패. 두 실패는 아직 연결하지 않은 02~07 통합 영상에 대한 `data-renderer=video` 기대값이다. 기대값을 완화하거나 검사를 제외하지 않으며, 실제 영상 통합 뒤 전체 회귀를 재실행한다.
- 하단 잔여 영역·지연 페인트 누출·폴드 장면 유지·작은 화면 문구 배치·세로 모드·입구/출구 검사는 통과.

## 최종 검증 예정

각 원본의 작업 ID·해시·전체 재생·내용 검수, 번호 순서와 장면 접합, 모든 테스트, 모바일·폴드·데스크톱 시각 검수, 최신 성능 측정과 Pages 빌드를 확인한다. 실기기 전체를 시험한 것으로 보고하지 않는다.


회사 소개·기능·키보드 메뉴·JS 없는 화면·검은 첫 화면을 390 / 768 / 1440 / 1920에서 검사해 16건 통과했다. 첫 화면 Lighthouse 실험 측정은 모바일 Performance 84 / Accessibility 100 / SEO 100, LCP 3.55초, CLS 0, TBT 171ms였다. 이미지 불투명도 진입에 따른 표시 지연을 확인해 모바일 이미지 진입 애니메이션을 제거하고 800w 반응형 이미지를 추가했다. 이는 최종 개선 점수를 달성했다고 주장하는 기록이 아니며 수정 후 별도 측정한다.

첫 진입에서 동일 영상의 약 1초 부유·반사광을 무음 재생하고 스크롤이 이어받는 단일 컨트롤러를 구현했다. 화면 이탈·문서 숨김·정리 시 멈춘다. 이 변경의 실제 영상 재생, 중간 로딩 시 첫 프레임 노출 방지, 35초 마스터 길이를 검증하는 테스트를 추가했으며, 전체 마스터가 준비되기 전에는 통과로 표시하지 않는다.

별도 브라우저 컴포넌트 점검은 채택된 01→02 웹 인코딩과 정상 HTTP Range 응답을 사용해 통과했다. 첫 무음 진입 약 1.05초 후 정지, 같은 컨트롤러의 전진·역방향 탐색, 중간 재생 위치를 요청한 뒤 목표 프레임에서 첫 표시, src 및 재생 정리를 확인했다. 이는 아직 미완성인 35초 전체 마스터의 사이트 검증을 대체하지 않는다.

04→05 첫 결과는 전체 디코딩을 통과했지만 큰 타원형 큐브 궤도가 보여 시각 검수에서 미채택했다. 원인은 05 참조 이미지의 곡선 연결 궤적이었다. 05와 06의 해당 경로를 각진 열린 조각 흐름으로 수정했으며, 같은 04 끝 프레임에서 수정 05로 다시 1회 접수했다. 수정 영상 검수 전에는 해당 결함이 최종 해결됐다고 표시하지 않는다. 미채택 원본과 입력 이미지·해시는 로컬 제작 이력에 보존한다.
