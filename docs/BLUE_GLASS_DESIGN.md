# SNC Blue Glass — 01~07 리디자인

## 방향

사용자 제공 7개 프레임과 최신 검은 배경 지시를 기준으로 설계한다. 반사되는 검은 바닥, 깊이 있는 건축 공간, 블루 유리 블록을 하나의 시각 언어로 사용한다. 일반적인 흰 카드·배경 그라디언트·장식용 체크마크 대신 실제 프레임의 공간을 크게 보여준다.

- 색상: Black #000000, Panel #070B12, Blue #216BE4, Sky #36A4ED, Navy #21386D, White #FFFFFF.
- 본문: 기존 로컬 SNC Sans. 영문 디스플레이: 기존 SNC Display. 한글은 읽기 쉬운 굵기와 행간을 유지한다.
- 배치: 첫 화면은 중앙의 입체 SNC를 중심으로 넓게 연다. 소개 문구와 문의 동작은 아래쪽의 안정된 읽기 영역에 놓는다. 이후 02~07 영상은 짧은 스크롤 장면으로 연결한다.
- 상세 내용: 회사 소개는 넓은 두 열, 사업 분야는 이미지가 들어간 세 개의 가로 행, 기술 연결은 선명한 블루 연결도, GitHub는 검은 콘솔 표면, 문의는 넓은 마지막 장면으로 구성한다.
- 모바일: 영상 구도와 텍스트 영역을 상하로 구성하고 고정 헤더·안전 영역을 고려한다. 폴드의 너비 변경 시 읽기 위치를 보존하고, 이전 하단 잔여 영역·지연 재측정 회귀 검사를 유지한다.

## 영상 순서

| 프레임 | 역할 | 움직임 |
|---|---|---|
| 01 | 브랜드 첫 화면 | 입체 SNC에서 천천히 물러나며 깊이 표현 |
| 02 | 업무와 기술의 공간 | 중앙 SNC를 향한 부드러운 진입 |
| 03 | 엔지니어링 | 유리 블록 옆을 따라가는 이동 |
| 04 | ESH | 현장과 업무를 상징하는 경로를 따라 전진 |
| 05 | 기업 시스템 | 구조 사이의 연결과 빛 흐름 |
| 06 | 웹 경험 | 빛 경로와 건축 공간의 연속적인 전진 |
| 07 | 다음 프로젝트 | 연결 구조에서 넓은 공간으로 이동 |

무료 외부 도구에서 사용자 원본을 참조해 장면별 영상을 생성한다. 생성 전 프롬프트·모델·무료 설정을 확인하고 완료한 작업은 중복 제출하지 않는다. 실제 원본 다운로드·해시·전체 디코딩·내용 검수를 마친 영상만 사이트에 연결한다. 사진에 CSS 이동만 적용한 결과를 생성 영상으로 표시하지 않는다.
