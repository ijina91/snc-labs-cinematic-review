# SNC 블루 유리 리디자인 교차 검토

이 문서는 실제 구현과 검증 근거의 검토 기록이다. 외부 심사나 여러 검토자가 참여했다고 주장하지 않는다. 같은 구현을 장점 중심과 결함 중심의 두 관점으로 분리해 검토한다. 실측 결과와 남은 한계를 주관적 점수보다 우선한다.

## 긍정 검토

- 브랜드: 사용자가 제공한 01~07의 검정·블루 유리 건축 공간을 중심으로 전체 웹 화면을 구성했다. 명함의 블루·네이비를 유지하며 녹색, 회전 체크마크, 원형 화면 안내는 추가하지 않았다.
- 표현: 일곱 구간이 하나의 플레이어를 공유하고 실제 앞 영상의 마지막 프레임을 다음 영상의 시작 이미지로 사용한다. 문구는 HTML로 분리해 확대·키보드·정적 읽기를 유지한다.
- 내용: ESH·안전작업허가, SAP·기업 시스템, 웹 개발의 확인된 업무를 보존했다. 고객명, 미확인 실적·서비스·개인 연락처를 추가하지 않았다.
- 문의: 서비스별 상세 설명과 문의 앵커, 대표전화 링크가 연결된다. 영상 감상 중에도 회사 소개와 문의로 바로 이동할 수 있다.
- 반응형: 좁은 화면에서는 영상 전체 형태와 문구의 읽기 영역을 분리하고, 낮은 가로 화면과 모션 축소에서는 정적 흐름을 사용한다.
