# 01~07 연속 모션 — 수정 제작 기준

## 사용자 피드백 반영

v1의 01~04는 카메라 이동에 편중됐고 조각의 부유·정렬·반짝임과 전체 연결이 부족하다는 피드백을 받았다. 해당 영상은 미채택 검토본으로 보존한다. 기존 Slack 파일을 새 완성본으로 설명하지 않는다.

## 공통 물리·빛 규칙

- 큰 SNC와 건축 구조는 형태를 유지한다. 주변 작은 유리 큐브는 자기 크기의 1~2배 범위에서 각기 다른 위상으로 떠오르고 가라앉고 5~15도 정도 가볍게 기울어진다. 전체 장면의 줌만으로 조각이 움직였다고 판단하지 않는다.
- 중앙 유리 블록의 일부 층은 작은 간격으로 열리고 다시 정렬된다. 글자 전체의 가독성, 블록 개수와 단단한 면·모서리를 유지한다. 녹거나 튀어나오거나 새로운 물체가 생기는 동작은 제외한다.
- 블루·흰색 빛이 왼쪽 전경에서 오른쪽 깊은 공간으로 전달된다. 유리 면과 모서리의 작은 하이라이트는 부드럽게 이동한다. 모든 조각이 동시에 켜지거나 화면 전체가 번쩍이지 않는다.
- 바닥은 고정된 고광택 검은 석재다. 조각의 움직임과 빛에 맞춰 반사의 위치·밝기가 바뀌며 물처럼 출렁이지 않는다. 그림자와 반사의 방향은 조명 및 카메라와 일치해야 한다.
- 움직임은 경계에서 멈췄다가 재시작하지 않는다. 카메라의 이동 방향, 속도, 작은 조각의 위상과 빛의 흐름을 다음 구간으로 넘긴다.
- 원본의 검정·SNC 블루·스카이 블루·딥 네이비·흰색을 보존한다. 인쇄된 메뉴·제목은 제작용 이미지에서 분리하고 실제 웹 텍스트로 표시한다.

## 순서와 연결

| 구간 | 카메라 | 조각·빛의 동작 | 연결 기준 |
|---|---|---|---|
| 01→02 | 큰 SNC에서 넓은 공간으로 뒤로 이동하며 완만한 옆 방향 호 형성 | 가까운 큐브의 부유·미세 회전, S→N→C로 이어지는 빛의 파동 | 02의 정확한 구도에 도달; 다음 옆 이동과 이어지는 속도 |
| 02→03 | 같은 옆 방향 호를 이어 전경 유리 블록으로 접근 | 전경 큐브의 서로 다른 위상, 유리 면에 이동하는 흰 하이라이트 | 03의 블록·기둥 위치 및 빛 경로 |
| 03→04 | 블록 옆을 지나 기둥 경로로 진입 | 얇은 유리 층이 미세하게 열리고 정렬; 작은 큐브는 독립 부유 | 04의 기둥과 바닥 선을 같은 방향으로 통과 |
| 04→05 | 바닥의 빛 경로를 따라 연결 구조로 접근 | 빛의 전달에 맞춰 연결 조각이 순서대로 밝아짐 | 05의 두 구조와 연결 경로 |
| 05→06 | 연결 구조를 지나 건축 경로로 이동 | 기존 연결 큐브가 경로를 따라 흐르며 간격 유지 | 06의 기둥·유리 및 먼 연결 구조 |
| 06→07 | 경로에서 데이터 모듈 쪽으로 완만하게 이동 | 각진 작은 유리 큐브의 부유, 모듈 내부 빛과 반사 변화 | 07의 모듈·노드 배치 |
| 07 마무리 | 마지막 구도에서 작은 안정적 이동 | 조각의 부유와 약한 빛 흐름 지속 | 다음 프로젝트 CTA를 읽을 수 있는 안정된 화면 |

## 영상 합격 기준

1. 01→02 샘플에서 카메라를 제외한 조각의 상대 움직임과 국소적인 빛 변화가 보인다.
2. 각 구간의 시작·끝은 인접 키프레임을 참조한다. 별도 장면을 단순 페이드로 연결한 것을 연속 촬영으로 표시하지 않는다.
3. 연결 프레임의 구도, 바닥 선, 카메라 방향과 속도, 조각 위치와 빛의 위상이 튀지 않는다.
4. 조각의 재질과 형태가 유지되고 텍스트·로고가 배경에 새로 생기지 않는다.
5. 모바일 축소에서도 움직임과 반짝임이 보이며 읽기 영역을 방해하지 않는다.
6. 전체 디코딩과 실제 프레임 검수를 구분해 기록한다. 조각이 사실상 정지해 있으면 재제작 대상으로 둔다.

## 웹 적용

첫 화면과 이후 소개를 서로 다른 소스로 재시작하지 않고 01~07의 단일 플레이어·단일 진행률로 설계한다. 기본 스크롤, 역방향 이동, Reduced Motion, 모바일 SVH/LVH 읽기 영역과 부모 페인트 클리핑, 폴드 읽기 위치 보존을 유지한다. 동영상이 없거나 실패하면 정적 키프레임과 실제 회사 소개를 읽을 수 있어야 한다.

## 원형 장식 제외

사용자의 추가 지시에 따라 07의 원형 노드와 곡선 연결선을 이미지 편집으로 제거했다. 원본 수정 전 이미지는 로컬 기록에 보존한다. 전체 영상에서 원형 고리·공·구체·후광이 새로 생성되면 검수 불합격이며 프롬프트와 키프레임 모두 이 기준을 적용한다.
